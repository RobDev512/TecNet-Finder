# CASO I1: Error léxico por palabra reservada mal escrita

IP 192.168.1.0 MAS /24 HOSTS 50 NAME Oficina
Salida esperada: caso inválido. Códigos esperados: LEX-001, SIN-002. Debe generar error léxico porque MAS es un identificador fuera de lugar y error sintáctico porque después de la IP no aparece MASK.

# CASO I14: Error semántico por máscara fuera de rango

IP 192.168.1.0 MASK /31 HOSTS 50 NAME Oficina
Salida esperada: caso inválido. Código esperado: SEM-001. Debe generar error semántico porque la máscara /31 está fuera del rango permitido /8 a /30. Como la máscara no supera SEM-001, no se ejecutan sobre este bloque las comprobaciones de capacidad que dependen de un prefijo válido.

# CASO I15: Error semántico porque la IP no es dirección de red

IP 192.168.1.5 MASK /24 HOSTS 50 NAME Oficina
Salida esperada: caso inválido. Código esperado: SEM-002. Debe generar error semántico porque 192.168.1.5 no es dirección de red para /24. La red correcta sería 192.168.1.0.

# CASO I16: Error semántico por cantidad de hosts igual a cero

IP 192.168.1.0 MASK /24 HOSTS 0 NAME Oficina
Salida esperada: caso inválido. Código esperado: SEM-003. Debe generar error semántico porque la cantidad de hosts debe ser mayor que cero.

# CASO I17: Error semántico por cantidad de hosts demasiado grande para la red base

IP 192.168.1.0 MASK /30 HOSTS 50 NAME Oficina
Salida esperada: caso inválido. Códigos esperados: SEM-004, SEM-005. Debe generar SEM-005 porque una solicitud de 50 hosts requiere un bloque mayor que toda la red /30, y SEM-004 porque la capacidad total requerida también excede la capacidad disponible.

# CASO I18: Error semántico porque el total de subredes no cabe

IP 192.168.1.0 MASK /24 HOSTS 100,100,100 NAME Oficina
Salida esperada: caso inválido. Código esperado: SEM-004. Debe generar error semántico porque cada solicitud puede caber individualmente, pero los tres bloques VLSM requieren en total 384 direcciones y una red /24 solamente dispone de 256.

# CASO I19: Error semántico por redes base traslapadas

IP 192.168.1.0 MASK /24 HOSTS 50 NAME Oficina
IP 192.168.1.128 MASK /25 HOSTS 50 NAME Laboratorio
Salida esperada: caso inválido con procesamiento parcial. Código esperado: SEM-006. Debe generar error semántico porque la red 192.168.1.128/25 se traslapa con la red base 192.168.1.0/24.

# CASO I20: Errores mixtos léxicos, sintácticos y semánticos

IP 192.168.1.5 MASK /31 HOSTS 0 NAME Red @
IP 10.0.0.0 MAS /8 HOSTS 100,,200 NAME
Salida esperada: caso inválido con varios diagnósticos. Códigos esperados: LEX-001, LEX-002, SIN-002, SEM-001, SEM-003. Debe generar errores léxicos, sintácticos y semánticos. La primera instrucción produce SEM-001 por la máscara /31 y SEM-003 por HOSTS 0. SEM-002 no se evalúa en esa instrucción porque la relación entre IP y red depende primero de una máscara semánticamente válida.
